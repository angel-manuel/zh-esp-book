% Footnote formatting.
% The rule MUST have zero net height: a footnoterule that adds vertical space
% sends TeX's output routine into an infinite loop as soon as a page carries
% several footnotes (this is what broke the sibling ruso-esp-book build).
% The \kern values below cancel out, exactly as in the LaTeX default.
\setlength{\footnotesep}{0.9em}
\setlength{\skip\footins}{1.6em}
\renewcommand{\footnoterule}{\kern-3pt\hrule width 0.3\textwidth height 0.4pt \kern 2.6pt}
